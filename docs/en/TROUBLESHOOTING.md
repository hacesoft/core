# Troubleshooting

If activation fails, inspect server compatibility, `appinfo/info.xml`, file permissions and the Nextcloud log. Deploy only one copy of the app under its correct ID `hc_shared_app_core`.

If a dependent app cannot locate Core, check activation and JS/CSS loading order. For editor or map problems, review browser console errors and server logs. Back up your instance and check dependent apps before attempting removal.
