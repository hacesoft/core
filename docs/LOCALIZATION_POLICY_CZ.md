# Pravidla lokalizace aplikací Hacesoft

Při každé další úpravě aplikace se ověří jazyky proti společné sadě `cs`, `en`, `de`, `es`, `fr`, `it`, `nl`, `pl`, `pt`, `sk`, `uk`. Doplní se chybějící jazyky i překladové klíče, prověří se výběr jazyka podle Nextcloudu a aktualizuje seznam skutečně podporovaných jazyků. Přítomnost souboru není důkaz úplného překladu. Návody a vývojová dokumentace se vydávají pouze česky a anglicky.

Kontrola zahrnuje tlačítka, formuláře, dialogy, stavové zprávy, přístupné popisky a ukázkové texty. Jazykové varianty jako `pt_BR` nebo `de-DE` se vyhodnotí proti základnímu jazyku. Nepodporovaný jazyk i chybějící jednotlivý překlad používají angličtinu (EN). Převzaté komponenty Core se kontrolují samostatně; žádný návod nesmí slibovat úplné překlady, které v kódu nejsou.
